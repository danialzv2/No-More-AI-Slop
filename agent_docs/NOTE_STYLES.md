# Word Documents, Reports, and Tutorials

Use this guide with the shared writing rules in [AGENTS.md](../AGENTS.md) for Word documents and formal reports or tutorials. For study notes in Word, use these formatting rules alongside the learning guide's content rules.

## Writing Style

- Use an appropriate academic tone for reports. State the purpose and organize the sections around what the reader needs to know.
- Explain necessary technical terms when they first appear.
- For tutorials, give clear steps in a logical order and include examples where useful.

## Microsoft Word Formatting

- Use Times New Roman throughout the document, including tables and references.
- Use black text only, including headings, captions, references, and hyperlinks. Avoid coloured fills and decorative colour accents.
- Set the document title to 12 pt.
- Set every section title to 12 pt and apply the actual Microsoft Word paragraph style named `Heading 1`. Do not simulate headings using bold text alone. If subsections are needed, apply the same requirement to their titles unless the user requests a different heading hierarchy.
- Set body text, bullet points, numbered steps, table text, captions, and reference entries to 11 pt.
- Apply the Microsoft Word table style named `Table 1` to every table. This is a table style requirement, separate from a table caption or number.
- If the template does not contain `Table 1`, create and apply a custom table style with that exact name, using black text, simple black borders, and no coloured fills. Do not silently substitute another table style.
- Ensure the applied styles use these font, size, and colour settings, rather than relying on template defaults.
- When working in a format that does not support Word styles, follow the writing requirements and carry these formatting requirements into any Word export. Do not claim Word styles were applied to a plain-text or Markdown file.

## Report and Tutorial PDFs

- When exporting a Word document to PDF, apply the Word styles to the source file before export.
- For a PDF created directly, match the Word guide's visible typography, sizes, and table treatment. Check the exported pages for legible text, consistent headings, and clean page breaks.
- For PDFs exported from slides, use the slide layout from [LEARNING_STYLES.md](LEARNING_STYLES.md).

## References and Citations

- Use APA style, defaulting to APA 7th edition unless the user or assignment specifies another edition.
- Use APA author-date in-text citations and provide a matching reference list.
- Verify each reference against the original publication, an official publisher page, a DOI record, or another authoritative source before including it.
- Check that the source supports the claim being cited and that the author, publication date, title, and publication details are accurate. Verify DOI and URL details where applicable.
- Never invent references, authors, dates, titles, DOIs, URLs, quotations, or page numbers.
- If a source cannot be verified, omit it or clearly identify the verification gap to the user. Do not present it as a verified reference.
- Ensure every in-text citation has a matching reference entry and every reference entry is cited in the document.
- Arrange reference entries alphabetically and use APA hanging indents in Word documents.

## Final Review

- Check the English level, clarity, and absence of em dashes.
- For Word documents, verify Times New Roman, black-only formatting, 12 pt titles and section titles, and 11 pt writing and points.
- Confirm that every section title uses `Heading 1` and every table uses `Table 1`.
- Check APA formatting, citation-to-reference matching, and source verification before delivery.
